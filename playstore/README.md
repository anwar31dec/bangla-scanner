# Play Store publishing kit – Bangla Scanner

Everything needed to publish `com.codeinherit.banglascanner` (v1.2.2, build 7) on Google Play. Start with `release/RELEASE_CHECKLIST.md`; it walks through Play Console step by step and points to the files below.

```
playstore/
├── README.md                      this file
├── package_name.txt               application ID, version, signing key and IDs in one place
├── release/
│   ├── RELEASE_CHECKLIST.md       build, sign, Play Console setup, testing track, production
│   └── release_notes_1.2.2.txt    "What's new" (en-US + bn-BD blocks, ≤500 chars each)
├── listing/
│   ├── en-US/  title.txt · short_description.txt · full_description.txt
│   └── bn-BD/  title.txt · short_description.txt · full_description.txt   (reuse for bn-IN)
├── policy/
│   ├── privacy_policy.md          source text
│   ├── privacy_policy.html        published at https://anwar31dec.github.io/bangla-scanner-docs/privacy-policy.html
│   ├── data_safety_form.md        answers for the Data safety questionnaire
│   ├── data_safety_bangla_scanner.csv   same answers in Play's CSV format → Data safety → Import from CSV
│   └── content_rating_questionnaire.md   IARC answers + all other "App content" declarations
└── graphics/
    ├── app_icon_512.png           store icon, 512×512 PNG, full name on the page (rendered from tool/icon/icon.svg)
    ├── app_icon_1024.png          same artwork at 1024 px
    ├── app_icon_512_letter.png    previous single-letter icon, kept for reference
    ├── feature_graphic_1024x500.png   rendered by tool/store/make_store_graphics.py
    └── screenshots/
        ├── phone_bn/  bn_01 … bn_08: framed 1080×1920 screenshots, Bangla captions  → bn-BD listing
        ├── phone_en/  en_01 … en_08: same screens, English captions                 → en-US listing
        └── raw/       untouched device captures (1080×2340), the input for the script
```

## Where the screenshots came from

Captured on the connected Samsung (1080×2340) from the installed dev flavour (same UI as prod, no app-lock PIN) using a sample Bangla letter rendered with the app's Hind Siliguri font, so no personal documents appear. The status bar and navigation bar are cropped out in the framed versions. The ID card screen was captured from the prod build.

The framed versions and the feature graphic are generated by `python3 tool/store/make_store_graphics.py` (Pillow with libraqm for Bangla shaping): warm paper background, left-aligned caption in the app's green, and the screenshot itself with rounded corners and a soft shadow running off the bottom edge, no fake phone bezel. Captions, colours and crop bounds are constants at the top of that script; edit and re-run to regenerate everything.

If you prefer plain screenshots without captions, the files in `raw/` can be uploaded directly after cropping the status bar (Play accepts 9:16 to 16:9; 1080×2340 is 9:19.5, so crop to 1080×1920).

## Character limits (already respected)

| Field | Limit | en-US | bn-BD |
| --- | --- | --- | --- |
| App name | 30 | 26 | 27 |
| Short description | 80 | 73 | 64 |
| Full description | 4000 | ~2700 | ~2500 |

## Things only you can do

1. Pay for / verify the Play Console developer account.
2. Privacy policy is live at https://anwar31dec.github.io/bangla-scanner-docs/privacy-policy.html (public repo `anwar31dec/bangla-scanner-docs`, GitHub Pages from `main`). Use that URL in Play Console.
3. Decide the developer name shown on the store (the policy says "Code Inherit (Anwar Hossain)"; change it in `privacy_policy.md`/`.html` if you want something else).
4. Run the 14-day closed test with 12 testers if your Play account is a personal account created after November 2023.

## Code change made while preparing this kit

`android/app/src/main/AndroidManifest.xml` now sets `flutter_deeplinking_enabled=false`. Without it, opening a photo or PDF with the app ("Open with" / ACTION_VIEW) while the app was already running showed a red "Page Not Found – no routes for location: content://…" screen because Flutter pushed the file URI to go_router as a route. Verified on the device with the rebuilt dev flavour: the file now opens in the editor. Rebuild the prod bundle so the fix ships.
